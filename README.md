# FL Agenda — Desktop (Electron + TypeScript)

Sistema de gerenciamento para estética e beleza. Aplicativo desktop construído com **Electron** e **TypeScript**, seguindo arquitetura **Vertical Slice**.

---

## Pré-requisitos

- Node.js >= 20
- npm >= 10

## Instalação

```bash
npm install
```

## Executar

```bash
npm start
```

## Desenvolvimento

```bash
# Compilar e rodar com logs
npm run dev

# Watch mode (compilação contínua)
npm run watch
```

## Stack

| Camada | Tecnologia |
|---|---|
| Desktop | Electron 31.x |
| Linguagem | TypeScript 5.x |
| Validação | Zod 3.x |
| Estado | Zustand 4.x |
| Backend/API | Supabase |
| Estilização | CSS Vanilla |
